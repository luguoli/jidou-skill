# 记兜 jidou · 随手记、AI 笔记、备忘录、待办清单与提醒 Skill

**简体中文** | [English](README.en.md)

**聊天里的随手记。记想法、存资料、列待办、设提醒。**

记兜（jidou）是一个用于 **随手记、AI 笔记、便签备忘录、待办事项和定时提醒** 的 Agent Skill。把 AI 助手当作随时可用的记事本：快速记录灵感，收藏链接和阅读摘录，管理任务清单，设置生日、农历和循环提醒，还能习惯打卡、整理周报、积累个人知识库。

An Agent Skill for quick notes, note-taking, memos, bookmarks, to-do lists, task management, recurring reminders, habit tracking, and personal knowledge management.

> 「随手记一下：周报能不能从聊天记录自动生成。」
>
> 「每月5号交房租，提前两天提醒。」
>
> 「关于老张的那些事，我都记哪了？」

## 你可以用记兜做什么

| 你想做的事 | 常见用法 |
|---|---|
| 随手记与便签备忘录 | 随手记录、随手记事、快速记录、速记、记事本、聊天笔记，想到什么先记下来。 |
| 灵感记录与资料收藏 | 收集想法和碎片记录，收藏链接、保存阅读摘录和读书笔记，随时接着补充。 |
| 待办清单与任务管理 | 管理待办事项、任务清单（Todo / To-do list）、截止日期和事项跟进，安排每天要做的事。 |
| 定时提醒与日程提醒 | 为事件设置提前提醒，也能安排生日提醒、纪念日提醒和农历提醒。 |
| 循环提醒与重复事项 | 设置交租提醒、缴费提醒、续费提醒，或每天、每周、每月重复提醒。 |
| 习惯打卡与时间管理 | 记录运动、读书等每日打卡，做习惯追踪，查看待办进展。 |
| 知识管理与个人知识库 | 搜索旧笔记，整理同一主题的记录，逐步积累自己的第二大脑。 |
| 周报、复盘与定时任务 | 汇总工作记录，整理周报、工作复盘和月度复盘；接好相应能力后定时自动整理。 |

## 亮点

- **随手记，开口就能记录。** 不用背指令或填表；一句话里有几件事，就分别记好。
- **便签、备忘录和资料收藏放一起。** 想法、链接、阅读摘录都能保存，摘要方便浏览，原话随时回看。
- **灵感记录可以接着补充。** 今天记一点，下周再补一点；同一主题的记录能串起来回看。
- **待办清单能跟进到完成。** 调整截止日期、标记完成、查看未完成任务，方便安排下一步。
- **定时、循环和农历提醒。** 生日、纪念日、交租、缴费都能设提醒，也能改期、静音或跳过一期。
- **笔记能整理，进展能复盘。** 查找旧记录、回顾习惯打卡、整理个人知识库；接好相应能力后定时整理周报。

## 开始使用

在终端中运行以下命令安装（需 Node.js/npm），按提示选择要安装到的 AI 助手：

```bash
npx skills add luguoli/jidou-skill
```

也可以直接下载 [技能包](https://github.com/luguoli/jidou-skill/archive/refs/heads/main.zip)，通过 AI 助手的技能导入功能安装；也可以把仓库地址发给支持安装技能的助手：

> 帮我安装记兜：https://github.com/luguoli/jidou-skill.git

安装后，直接试着说：**「记一下：这周想把书桌整理一下。」**

支持中文和英文自然表达，跟随你的语言回复；原话按原样保留，不会翻译后覆盖。

**不限平台，不限 Agent，支持标准 Skill 格式即可加载记兜。** [安装说明](references/install.md)

## 完整使用示例

下面的话可以直接对助手说，换成你自己的内容即可。

### 随手记、灵感记录与资料收藏

| 想做什么 | 可以这样说 |
|---|---|
| 随手记想法 | 随手记一下，周报能不能从聊天记录自动生成？ |
| 存参考 | 这个讲缓存穿透的链接留着，标签加上后端、性能。 |
| 留摘录 | 把这段话原样记下来，注明来自《书名》第32页。 |
| 记疑问 | 记个疑问：为什么月底对账总是对不上？ |
| 留决策 | 定了，以后用模板A，因为客户看起来更清楚。把原因也记下。 |
| 记计划 | 记个计划：三个月内把内容号做起来。 |
| 记待办 | 下周三把合同发给老张。 |
| 先记着，不定日期 | 报税这事先记着，还没定什么时候。 |
| 记事件 | 11月20号早上9点体检。 |
| 一次记多件事 | 记两件事：周五前交方案；另外想试试把周报自动化。 |
| 自动归类 | 记一下，周末清洗空调；还有月底缴电费。 |
| 标注优先级 | 这件事周四截止，会影响别人，优先处理。 |

### 定时提醒、循环提醒与农历提醒

| 想做什么 | 可以这样说 |
|---|---|
| 一次性提醒 | 11月20号早上9点提醒我体检。 |
| 固定提前量 | 周五下午3点开会，提前一天提醒我。 |
| 自定义提前量 | 周五下午3点开会，提前两小时提醒，开会时间不变。 |
| 每天提醒 | 每天晚上9点提醒我读书。 |
| 工作日提醒 | 每个工作日早上9点提醒我列今天的重点。 |
| 一周多次 | 每周一、周四晚上8点提醒我运动。 |
| 隔周提醒 | 从11月9日开始，每两周周一早上9点提醒我做一次复盘。 |
| 每隔几天 | 从11月8日开始，每3天早上9点提醒我检查一次植物。 |
| 每月固定日期 | 每月5号交房租，提前两天提醒。 |
| 每月月底 | 每月最后一天晚上6点提醒我对账。 |
| 每年提醒 | 每年3月28日早上9点提醒我纪念日。 |
| 农历提醒 | 妈妈生日是农历三月二十八，每年提前一天提醒我。 |

工作日默认指周一至周五；需要按节假日调休时，可以再说明地区和要求。

### 待办管理、补充、改期与完成

| 想做什么 | 可以这样说 |
|---|---|
| 追加想法 | 上次那个周报自动化，又想到一点：可以先提取本周完成的待办。 |
| 纠正记录 | 刚才记错了，是下周三，不是这周三。 |
| 修改一次性安排 | 把发合同这件事改到明天下午3点。 |
| 只改这次提醒 | 房租这次改成周六提醒，以后仍按原来的计划。 |
| 长期调整 | 以后运动提醒都改到周三晚上8点。 |
| 暂时静音 | 这个运动提醒，这周先别提醒我。 |
| 完成一件待办 | 合同已经发给老张了，标记完成。 |
| 完成循环中的这一次 | 这个月房租已经交了，下个月继续提醒。 |
| 跳过一期 | 这周的运动提醒跳过，下周照常。 |
| 撤销误操作 | 刚才那次打卡弄错了，撤销这次完成记录。 |
| 结束整个循环 | 这个订阅已经取消，以后不需要再提醒续费。 |
| 归档旧记录 | 这个想法暂时不做了，先归档，记录保留。 |

### 定时任务与自动整理

| 想做什么 | 可以这样说 |
|---|---|
| 定时跑脚本 | 每天早上7点执行已经配置好的日报脚本。 |
| 定时检查接口 | 每小时检查这个接口，有变化再告诉我。 |
| 定时整理记录 | 每周一早上8点整理上周记录，生成一份周报。 |
| 多步执行 | 每天下午6点拉取数据、生成日报，再把结果发给我。 |
| 暂停执行 | 这个日报任务先停一下，等我说恢复再继续。 |
| 恢复执行 | 恢复刚才暂停的日报任务。 |

提醒和定时执行需要先开通相应能力，助手会说明是否已就绪。提醒可能受扫描周期和运行状态影响；执行任务需先配置好要调用的工具。

## 使用时不必拘泥于这些说法

用你平时的表达即可，分类不对可以直接纠正。普通闲聊不会自动记入；明确说要保存到其他地方时，会尊重你指定的位置。
