# 记兜 · jidou

聊天里的个人收集箱。把随口说的想法、待办和琐事接住，保留原话、自动归类，需要时找回、提醒或执行。

> 「记一下：周报能不能从聊天记录自动生成。」
> 「每月5号交房租，提前两天提醒。」
> 「关于老张的那些事，我都记哪了？」

## 能做什么

| 能力 | 行为 |
|---|---|
| 记录 | 一件事一行，摘要与原话分开；按类型、领域、标签、相关人归类 |
| 线索 | 同一主题多次补充，共用稳定编号，回看演进 |
| 回读和整理 | 按人、日期、主题、状态找回；整理、复盘、习惯打卡 |
| 提醒 | 一次性、循环、自定义提前量、静音和单次改期；保留真实事件时间 |
| 定时执行 | 使用已接好的平台后台工具；需要时可明确选择本地命令扩展 |

普通闲聊不自动保存，指定其他保存位置时尊重该位置。[完整使用示例](references/onboarding.md)。

## 先使用所在平台已有的能力

记兜首先是一份标准技能说明，优先使用用户已有的资料库、表格、连接器和调度服务。**加载或安装技能不要求先装 Python，也不会自动创建 SQLite 数据库。**

- **WorkBuddy 云端：** 保留原有 library 云端数据表和 automation-task-manager 流程，继续使用已有表、配置和任务 ID。工具与权限须在实际云端环境核验，不要求用户为云端执行先在电脑上安装 Python。
- **Codex、Claude Code、TRAE 等：** 安装技能后，先检查当前 Agent 已连接的存储与后台能力。加载同一个 SKILL.md 不代表自动拥有 WorkBuddy 的接口。
- **缺少存储或调度：** 如实说明哪些能力未就绪；不偷偷建另一份库，也不把聊天中的候选内容说成已持久保存。
- **明确需要本地独立运行：** 才选用随包的 Python/SQLite 扩展，见 [可选本地方案](references/local-runtime.md)。

## 数据保存在哪里

| 方案 | 实际保存位置 |
|---|---|
| 原有 WorkBuddy 云端方案 | library 管理的云端「记兜」数据表；按表 ID 和记录 ID 读写 |
| 可选本地方案 | 用户数据目录中的 jidou.sqlite3；保存本地记录、提醒队列和执行回执 |
| Excel / CSV 导出 | 导出的副本或备份，不自动替代正在使用的数据源 |

云端数据表有表格界面，但本技能原有流程并不直接读写 .xlsx 文件。用户明确指定已有 Excel 工作簿时，走可用的表格工具并沿用该目标；当前包没有新增通用 Excel 存储适配器，不能宣称它会自动读写任意工作簿。
SQLite 是另一种明确选择的本地存储，不是云端表的缓存，也没有自动同步或替换云端数据。

## 安装技能

下载或克隆完整仓库，通过平台的技能导入功能安装，或将完整技能包放入该加载器的 jidou 目录。导入、复制或解压本身不需要 Python：

```bash
git clone https://github.com/luguoli/jidou-skill.git
```

没有 Git 时也可下载仓库 ZIP。WorkBuddy 使用技能导入/上传入口，云端任务要确认技能在实际执行环境可见；其他 Agent 的目录及可选复制工具见 [安装说明](references/install.md)。
不要只复制 SKILL.md 而漏掉 references 和随包脚本。安装技能不等于接好存储或开启后台，先找回现有记录，不默认初始化。

入口是标准 **SKILL.md：YAML 元数据头 + Markdown 正文**，[格式说明](references/format.md)。

## 什么时候才需要 Python

| 操作 | 要求 |
|---|---|
| 加载技能说明、导入或手动复制技能包 | 无 Python 前置要求 |
| 使用所在平台已有的存储/调度工具 | 遵循该工具自身的运行要求；依赖检查发生在实际执行环境 |
| 运行随包的云端渲染/校验脚本 | 执行位置需要 Python 3.10+、PyYAML 和可用时区数据 |
| 使用可选本地存储、安装脚本或本机后台 | 运行这些脚本的本机需要 Python 3.10+；按功能检查依赖 |

requirements.txt 是随包脚本的依赖清单，不是所有用户的安装步骤。平台已提供所需运行环境时直接复用；缺失时只报告该操作的依赖，不因此切换数据源。
本地扩展包含 Windows/macOS 后台配置入口，只有用户明确要求时才启用；不会随安装技能自动注册。它不提供跨电脑自动同步，也不保证休眠或注销后继续运行。

## 数据约定与维护

原21字段、类型、顺序和枚举保持不变，[schema.json](references/schema.json) 是机器定义，[数据约定](references/data-model.md) 解释含义。原文与摘要分开，密码或密钥不进入任何字段。
云端默认每小时扫描，本地可选后台默认每分钟唤醒，均默认22:00–08:00静默。排队、通道接受与用户读到分别核对，不承诺严格一次投递。

维护者可在开发环境安装脚本依赖并验证：

```bash
python -m pip install -r requirements.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```
