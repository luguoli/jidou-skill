# 功能清单与示范

装好之后先看这一页。看完你不需要记任何命令，只要知道**能说什么**。

## 一、能力总表

| # | 能做什么 | 你大概会这么说 | 会发生什么 |
|---|---|---|---|
| 1 | 记想法 | 「记一下：周报能不能自动生成」 | 存成「想法」，打标签、编线索号 |
| 2 | 记参考 | 「这个链接留着，讲缓存穿透的」 | 存成「参考」，链接 + 一句结论 |
| 3 | 记摘录 | 「书上有句：注意力是稀缺资源」 | 存成「摘录」，原话照抄不改写 |
| 4 | 记疑问 | 「为什么月底对账总对不上？」 | 存成「疑问」，等你哪天有答案再补 |
| 5 | 记决策 | 「定了，以后周报都用模板 A」 | 存成「决策」，两个月后还能查为什么这么定 |
| 6 | 记计划 | 「Q4 想做个内容栏目，分三期」 | 存成「计划」，首个节点进「到期」 |
| 7 | 记没定时间的待办 | 「报税这事先记着，没定什么时候」 | 存成「待办」，到期留空，不提醒 |
| 8 | 定时待办 | 「下周三前把合同发给老张」 | 存「到期」，到点提醒一次 |
| 9 | 提前量提醒 | 「提前一天提醒我」 | 存「提醒」= 提前1天，提醒时刻前移 |
| 10 | 循环任务 | 「每月5号交房租，提前3天提醒」 | 存「重复」，每次提醒后自动滚下一期 |
| 11 | 农历循环 | 「农历三月二十八是妈生日，提前一周」 | 每年重算公历落点，不会记错日子 |
| 12 | 事件（只需提醒） | 「11月20号体检」 | 存成「事件」，不需要勾「完成」 |
| 13 | 静音一段时间 | 「这个这周别提醒我了」 | 写「静音至」，期间跳过，到期自动恢复 |
| 14 | 改期 | 「改到明天下午3点提醒」 | 改「下次触发」，不改重复节奏 |
| 15 | 标记完成 | 「老张那事做完了」 | 状态改「已完成」，记「完成于」 |
| 16 | 不做了 | 「这个不做了」 | 归档，不删除，以后还能翻 |
| 17 | 跟进同一件事 | 「上次那个周报的想法，我又想到一点」 | 沿用原线索号，新起一行，日期自动带 |
| 18 | 回看演进 | 「周报那事我想到哪一步了」 | 按线索号按时间讲一遍，不念表格 |
| 19 | 翻旧记录 | 「我上个月记的关于定价的」 | 按关键词 + 时间范围检索 |
| 20 | 整理 | 「把这周的速记理一理」 | 按类型归并，未完成单独列，汇总成文档 |
| 21 | 复盘 | 「这个月我真正做完了哪些」 | 用「完成于」统计，算单件耗时 |
| 22 | **定时跑脚本** | 「每天早上7点执行这段命令，结果写回表」 | 建独立定时任务，准点执行 |
| 23 | **定时调 API** | 「每小时拉一次这个接口，变了告诉我」 | 建任务按 cron 请求并比对，没变化不出声 |
| 24 | **定时用技能** | 「每周一早上让它自动整理上周速记」 | 建任务，到点触发对应技能流程 |
| 25 | **定时做多件事** | 「每天8点：拉数据、生成日报、发给我」 | 建一个任务，按顺序执行多步 |
| 26 | 自动分领域 | 「记一下：空调该洗了」 | 判为「生活」，不用你说 |
| 27 | 按领域看 | 「工作上还有什么没做完」 | 只筛工作域，不混生活 |
| 28 | 标优先级 | 「这个很急，周四要交」 | 优先级「高」，配合截止日 |
| 29 | 随机回顾 | 「随便抽几条给我看看」 | 抽 3–5 条，时间散开，帮你筛掉过期的 |
| 30 | 习惯打卡 | 「每天跑步，记录我坚持了几天」 | 每次打卡写一条，能算连续天数 |
| 31 | 留原话 | 不用特意说，每条都自动留 | 你说的原样存在「原文」，一个字不改；以后问「我当时怎么说的」能调出来 |

第 1–21、26–31 项都落在速记箱里；第 22–25 项是**定时执行**，不占速记箱的扫描任务，每条单独一个准点任务（详见 SKILL.md「定时执行」一节）。

第 1–6 项是六种「记下来但不用提醒」的东西：想法、参考、摘录、疑问、决策、计划——都是存着以后用的，不是待办。

每条记录都会自动落到六个领域之一：**工作 / 生活 / 学习 / 健康 / 财务 / 其他**。体检吃药归健康，房租报销归财务，不用你说。这是让表在半年后还能翻得动的前提——混在一起的记录，三个月后就不想看了。

### 有些东西看着不像任何一类

不用为此纠结，也不要新造类型。按下表归：

| 你会记的 | 归到 | 怎么摆 |
|---|---|---|
| 会议纪要、通话记录 | 摘录 | 结论进内容，参会人进「相关人」，要跟进的事另起一条待办 |
| 购物清单、打包清单 | 待办 | 一项一条，同一线索号 |
| 今天花了 320 | 参考 | 金额写进内容；表不算账，要统计另建表 |
| 体重、血压 | 摘录 | 一个数一条，标签固定 `健康`，靠时间看趋势 |
| 某人的喜好、电话 | 参考 | 人名进「相关人」，以后按人筛 |
| 截图、PDF、录音 | 不收录 | 表不支持附件。存链接进「来源」，文件放资料库或网盘 |

**不往里存的四样**：密码和证件号（「执行内容」是明文）、需要算数的账目、需要多人协作的东西、附件本身（只存链接）。

## 二、十种类型，各是什么样

同样是「记一下」，存进去的东西不一样。下面每行都是一句话就能说完的事：

| 类型 | 你会怎么说 | 存成什么 | 用在哪 |
|---|---|---|---|
| 想法 | 「记一下：周报能不能自动生成」 | 内容 + 标签 + 线索号，状态「待看」 | 还没成形的念头 |
| 待办 | 「报税这事先记着，没定什么时候」 | 到期留空，不提醒 | 要做，但还没定时间 |
| 事件 | 「11月20号体检」 | 到期 `11-20`（没说钟点按当天 09:00），提醒「准时」 | 到点发生，不用勾完成 |
| 参考 | 「这个链接留着，讲缓存穿透的」 | 链接进「来源」，内容写一句结论 | 以后可能要查的资料 |
| 决策 | 「定了，以后周报都用模板 A」 | 类型「决策」，状态「已完成」+ 完成于当天 | 定下来的事，防止反复推翻 |
| 摘录 | 「书上有句：注意力是稀缺资源」 | 原话照抄，书名页码进「来源」 | 别人的话，想留着 |
| 疑问 | 「为什么月底对账总是对不上？」 | 类型「疑问」，状态「待看」 | 待解的困惑，不是待办 |
| 计划 | 「Q4 想做个内容栏目，分三期」 | 类型「计划」，首个节点写进到期，没有就留空 | 多步的事，还没拆完 |
| 复盘 | 「这次投放没起量，因为落地页太慢」 | 类型「复盘」，标签带项目名 | 事后的结论，不占待办 |
| 定时 | 「每天早上7点拉一次数据」 | 类型「定时」，执行「API」 | 到点自动做事，不是提醒 |

**区别在哪**：想法是「可能做」，待办是「要做」，事件是「会发生」，参考是「以后查」，决策是「已经定」，摘录是「别人的话」，疑问是「不知道」，计划是「分几步」，复盘是「已经过」，定时是「机器做」。

判断错了不用改，说一句「这条改成待办」即可，类型随时能换。

## 三、定时分两种，别混

「定时」这件事其实是两件不同的事，混在一起说，用户永远不知道自己能得到什么：

| | 定时提醒 | 定时执行 |
|---|---|---|
| 一句话 | 到点叫你一声 | 到点替你干活 |
| 例子 | 每周一 9 点提醒你交周报 | 每周一 8 点自动拉数据、生成周报 |
| 谁在跑 | 一个每小时扫表的公共任务 | 每条单独一个任务，按 cron 准点触发 |
| 精度 | **小时级**，可能早几分钟或晚几分钟 | **分钟级**，说 7:00 就是 7:00 |
| 你不在场 | 无所谓，回来了再看 | 照跑，结果写回表里 |
| 出错 | 下个小时再扫一次 | 有重试和超时，失败会留回执 |

### 提醒能设成什么样

| # | 形态 | 你大概会说 |
|---|---|---|
| 1 | 某天某时，一次 | 「11月20号早上9点提醒我体检」 |
| 2 | 提前量，任意长 | 「提前半小时」「提前2小时」「提前10天」都行 |
| 3 | 每天 | 「每天8点提醒我吃药」 |
| 4 | 每周某天或多天 | 「每周一、周四晚上8点」 |
| 5 | 每月某号 | 「每月5号交房租」 |
| 6 | 每月最后一天 | 「月底最后一天对账」 |
| 7 | 每年某日 | 「每年3月28日续保」 |
| 8 | 每年农历某日 | 「农历三月二十八是妈生日」 |
| 9 | 每 N 天 | 「每3天浇一次花」 |
| 10 | 工作日 | 「每个工作日9点半站会」 |
| 11 | 事件（只提醒，不用勾完成） | 「11月20号体检」 |
| 12 | 静音一段 | 「这周别提醒我了」 |
| 13 | 改期一次 | 「改到明天下午3点」 |

第 10 项的「工作日」不含法定节假日调休——长假照常提醒，嫌吵说一句静音即可。

### 执行能设成什么样

| 执行 | 做什么 | 你大概会说 |
|---|---|---|
| 脚本 | 跑一段命令 | 「每天7点跑这段脚本，结果写回表」 |
| API | 请求一个接口 | 「每小时拉一次这个接口，变了告诉我」 |
| 技能 | 触发某个流程 | 「每周一自动把上周速记整理成文档」 |
| 组合 | 多步串起来 | 「每天8点：拉数据、生成日报、发给我」 |
| 仅提醒 | 只推送，不做事 | 「到点提醒我就行」 |

除了上面五种，还有一种用法值得单说：**盯着看**。「这个价格跌到 800 以下就告诉我」「库存补上了说一声」——它算执行类（调接口），但没变化时一声不出，只有满足条件才通知你。和每天写一条"无变化"的任务不是一回事。

频率上能设：每 N 分钟、每小时、每 N 小时、每天、每天多个时段、工作日、每周某天、每周多天、每月某号、每季度首日，以及「明天下午3点跑一次」这种一次性的。

### 四条要提前知道的边界

1. **提醒的精度是小时级。** 说「提前10分钟」，实际会在那个小时内推到，可能早几分钟也可能晚几分钟。要卡到分钟，只能建成定时执行任务。
2. **定时执行看不到你电脑上的文件。** 「跑一下我桌面那个脚本」做不到，「用这段命令去取数据」可以。数据要么写在指令里，要么从接口或资料库现取。
3. **执行类任务最多 100 个。** 不为一次性的小事建任务，能用提醒说的就用提醒，跑完就删。
4. **循环任务用「提前2小时」这类非标准提前量时，重复日会按提醒日算。** 内容里会保留真实日期，比如「5号交房租（3号提醒）」，看到别以为改期了。

另外四种 cron 表达不了的频率——每两周、每月最后一天、农历、每 N 天——会建成「每天叫醒 + 当天判断该不该做」的形式。多叫醒几次没关系，多做一次才有关系。

## 四、完整示范

下面挑了几类展开成完整对话——想法、摘录、决策、循环待办、线索跟进、改口、回看、定时执行。没展开的（参考、疑问、计划、复盘、事件）看上一节那一行就够，说的时候不用挑类型词，按意思说就行。

### 示范 1 · 一句话存下来（想法）

> **你**：记一下，周报要是能从聊天记录自动生成，每周能省两小时
>
> **结果**：存入「想法」，标签 `效率、自动化`，线索号 `Q20261105-01`，状态「待看」
>
> **回你**：已记下，Q20261105-01。以后补充这件事会自动接在这个号下。
>
> **同时**：你这句话原样存进「原文」，一个字没改（包括"要是能"这种口语）。三个月后问「我当时怎么说的」，给你的就是这句原话，不是我整理过的版本。

### 示范 2 · 摘录一段别人的话（摘录）

> **你**：书上有句话想存一下——「注意力是稀缺资源，别用碎片信息换它」
>
> **结果**：「摘录」，原文照抄不改写，内容写一句要点，标签 `注意力、引用`，来源留空
>
> **回你**：存好了。要补书名的话告我一句，我填到「来源」里。

摘录和参考的区别：摘录是原话段落，参考是链接或资料，想逐字留存就选摘录。**摘录的原文进「原文」，要点进「内容」**——被摘的那段话可能是三百字，塞进「内容」会把表格撑得没法看。两者的出处一律进「来源」，不要塞进标签——标签只放主题词，混着放以后按主题筛就不准了。

### 示范 3 · 定下来的事（决策）

> **你**：定了，以后所有周报都用模板 A，不再每期重排
>
> **结果**：「决策」，状态「已完成」，记录时间与完成于都填当天
>
> **回你**：记下了。以后你问「周报模板用哪个」，我直接翻这条给你，不用再讨论一遍。

决策这类最容易被跳过——当时说得很清楚，两个月后谁都不记得为什么这么定。存下来就是为那一刻。

### 示范 4 · 带提醒的循环任务（待办 + 重复）

> **你**：每个月5号交房租，提前3天提醒我
>
> **结果**：「待办」/ 重复 `每月5号` / 提醒 `提前3天` / 下次触发 `2026-12-05`
>
> **回你**：记好了。下次提醒是 12月2日，之后每月自动滚。

到 12 月 2 日那场扫描，会推一条给你。你回「交了」，状态改完成、记录完成时间；回「这月晚点」，就写静音。

农历同理，说「农历三月二十八」就行，每年自动换算公历，不会记错日子。

### 示范 5 · 跟进一件事（线索）

> **你**：上次那个周报的想法，我又想到一点，摘要可以让 LLM 写
>
> **结果**：识别到同一线索，新起一行，沿用 `Q20261105-01`，日期是今天，状态改「进行中」
>
> **回你**：接到 Q20261105-01 下了，这是第 2 条记录。

判断「是不是同一件事」有歧义时，会先问一句，不猜。合错了比没合更麻烦。

### 示范 6 · 改口（最常用的四句）

这四句不用查记录、不用报编号，说人话就行：

| 你说 | 会发生什么 |
|---|---|
| 「这个这周别提醒我了」 | 写「静音至」本周日，期间跳过，到期自动恢复，**记录还在** |
| 「改到明天下午3点提醒」 | 只改「下次触发」，重复节奏不变，下次自动回到原周期 |
| 「老张那事做完了」 | 状态「已完成」，记「完成于」，提醒自动停 |
| 「这个不做了」 | 状态「归档」，不删，以后还能翻出来 |

静音和归档是两件事：静音是「先别吵我」，归档是「这事结束了」。

### 示范 7 · 回看与整理

| 你说 | 会发生什么 |
|---|---|
| 「周报那事我想到哪一步了」 | 按线索号顺着时间讲一遍，不念表格 |
| 「我上个月记的关于定价的」 | 关键词 + 时间范围检索，命中的给你看 |
| 「我当时是怎么说的」 | 逐字给你「原文」，不改错别字、不补标点、不顺成书面语 |
| 「把这周的速记理一理」 | 按类型归并，未完成的单独列，出一份汇总 |
| 「这个月我真正做完了哪些」 | 用「完成于」统计，算单件耗时 |
| 「随便抽几条给我看看」 | 抽 3–5 条，时间散开，顺手标出已过期的 |
| 「每天跑步，我坚持几天了」 | 每次打卡写一条，能算连续天数 |

### 示范 8 · 定时执行（不是提醒）

> **你**：每天早上7点，调这个接口拉昨天的数据，把条数写回表里
>
> **结果**：建一个独立定时任务（cron `0 0 7 * * *`），同时在速记箱登记一行，类型「定时」、执行「API」、执行内容填请求命令、任务 ID 填进去
>
> **回你**：任务已建，每天 07:00 执行，结果写入「上次结果」。想停就说「停掉那个拉数据的」。

四种执行形态，能组合（「执行」字段还有第五个选项「仅提醒」，那是不做事、只推送，所以不算执行形态）：

| 执行 | 说什么 | 例子 |
|---|---|---|
| 脚本 | 「每天7点跑这段命令」 | 清理临时文件、跑一次统计 |
| API | 「每小时拉一次这个接口，变了告诉我」 | 监控价格、盯接口状态 |
| 技能 | 「每周一早上自动整理上周速记」 | 触发本技能的整理流程 |
| 组合 | 「每天8点：拉数据、生成日报、发我」 | 一个任务里按顺序做多步 |

区别要分清：**提醒是到点告诉你，执行是到点做事**。做事可以完全不通知你，也可以做完汇报。

有一条限制必须提前知道：**定时任务跑在独立的执行环境里，看不到你电脑上的文件。** 所以「跑一下我桌面那个脚本」做不到，「用这段命令去取数据」可以。命令写在任务指令里、数据从接口或资料库取，这样才跑得通。

## 五、这些不用你交代

以下判断每次自动做，不用在话里说明：

- **类型**：按内容判断是想法、待办、事件、参考、决策、摘录、疑问、计划、复盘、定时
- **领域**：工作 / 生活 / 学习 / 健康 / 财务 / 其他，按内容判，判不准就问一句
- **优先级**：只有带明确截止时间、且你说了「急」「周四要交」这类才标高，其余留空
- **标签**：从内容里抽 2–4 个，不用你指定
- **线索号**：新事开新号，老事自动接上
- **日期**：取当天，不用你说「今天是几号」
- **夜间静默**：22:00–08:00 不推提醒，早上 8 点补上
- **合并推送**：同一件事有多个到期点，合成一条讲
- **保留原话**：你的原话优先，我只补必要背景

## 六、需要你确认的事

只有四类会先问：

1. **第一次使用、空间里又找不到已有的表** —「新建一套，还是你之前建过、我再找找？」
2. **判断是不是同一件事**有歧义时 —「这条接到 Q20261105-01，还是新开一个？」
3. **定时执行涉及外部写操作**时 — 发邮件、提交表单、调有副作用的接口
4. **主版本升级**（改存储形态、删字段）— 规范要求必须先确认

其余情况直接做，做完告诉你结果。
